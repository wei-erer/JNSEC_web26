路怎么走

这不是课表。课表按周排，这份按"你卡在哪儿"排。 什么时候觉得不知道下一步干什么，回来翻一眼。

这个站怎么用

三条，都是我自己踩过坑总结的：

  1. 别按顺序从头读到尾。每卷开头都有个目录，先扫一眼， 挑你当下最懵的那节看。看懂了就跳。
  2. 每个「实操」都真的做一遍。看懂和做出来之间隔着一条河。 这里的靶场都是故意写漏的，跑起来五分钟的事，别光读。
  3. 看不懂就去茶寮问，或者自己写一条。把踩到的坑记下来， 下次有人翻到这儿就不用再踩一遍。

入门大致分这几步

Web 安全的东西看着散，其实有个大致的递进。下面这条不是唯一的路， 但大部分人是这么走过来的：

阶段你会学到标志是
看得懂 HTML / HTTP / 工具链 能对着一个请求说出每个头在干什么，能自己起环境
打得进 SQL 注入、XSS、文件上传、命令执行、SSRF 拿到一个输入点，知道该试哪几种 payload
拿得下 越权、逻辑漏洞、JWT、反序列化 能看懂一段业务代码里"信任"断在哪儿
走得远 组合利用、代码审计、自动化 单个点打不动时，会去找两个点拼起来

第一讲只把"看得懂"这一层铺了一半。剩下的慢慢来，别急。

练手的地方

  • CTFHub 技能树 —— 国内入门最顺的一条线，按知识点排好了，每道题都有明确的考点。第一讲的作业就是它。
  • BUUCTF / NSSCTF —— 题多、杂、有真实比赛题。适合在 CTFHub 刷完之后换口味。
  • DVWA / Pikachu —— 专门的漏洞靶场，每一类漏洞分低中高三种防护等级，可以对照着看"修了之后为什么打不动"。想理解防御，这两个比做题有用。
  • 自己写一个。最有效的一步：用 phpstudy 起个页面，写一行 echo $_GET['name'];，然后想办法让它弹窗。懂了为什么能弹，就懂了 XSS。
一条界限

上面这些东西，全都在你自己的机器、或者明确授权给你练的靶场里。 不对任何没授权的站点做那些事 —— 这不只是纪律问题， 《网络安全法》第二十七条写得明明白白。手上有本事和手上有案底，差别就在这一步。

家伙一览

Burp代理抓包改包，主力
浏览器代理到 127.0.0.1:8080 就能用。前期只需要记住三个地方：Proxy 的 HTTP history、Repeater（改包重发）、Intruder（批量试）。
HackBar浏览器里的小扳手
页面内快速改参数、编码解码。比 Burp 快，但只能碰到它够得着的部分。
phpstudy本地起 php 站
文件丢 www 目录，浏览器开 127.0.0.1。用来写有漏洞的代码，然后自己打。
WSL / VMware随便弄坏的机器
Ubuntu 装一套。跑工具、跑靶场、装只在 Linux 上有的东西。
Yakit另一个视角
流量分析、被动扫描、批量 fuzz 比 Burp 顺手。和 Burp 互补，不是替代。
curl最朴素的请求工具
命令行里一行就能改头。脚本化、批量、复现的时候比图形界面可靠得多。
